# Formula 1
This is a revamp of the [Formula 1](https://www.formula1.com/) website using HTML, CSS, JS, and Bootstrap.

## Local development setup
1. Clone this repository into your machine.
2. Serve the website through localhost (follow step 3 if you are using an IDE like VSCode, otherwise follow step 4).
3. Open the project in VSCode and install the Live Server Extension from the marketplace.
4. Install python and run `python -m http.server 3000` on the root directory of the project.
